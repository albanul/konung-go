Ready-to-run bundles of the game and the network game's server. **The original game's files are not included**: copy them from your own copy of the game into the bundle's `assets/Konung` folder (see `README.txt` inside).

| Your computer | Download |
|---|---|
| Windows | `konung-…-windows.zip` |
| Mac with Apple silicon (M1, M2, M3, …) | `konung-…-macos-apple-silicon.zip` |
| Mac with an Intel processor | `konung-…-macos-intel.zip` |
| Linux PC | `konung-…-linux.tar.gz` |
| Linux on ARM (Raspberry Pi 4/5, …) | `konung-…-linux-arm64.tar.gz` |

1. Unpack it.
2. Copy the original game's files into `assets/Konung`.
3. Play alone: start `konung` (`konung.exe`). Play together: start `konung-server` on one computer and open `http://<its address>:7777/` in a browser, or join from the game's «Сетевая игра».

macOS: the first time, right-click the program → Open → Open.
